# \# Task Tracker CLI

# 

# Aplicaçao de linha de comando (CLI) desenvolvida em C# e .NET para gestao simples de tarefas no terminal.

# 

# Este projeto faz parte dos meus estudos do Card 1 (Fundamentos do C#) para obter a certificaçao conjunta da Microsoft + freeCodeCamp.

# 

# \---

# 

# \## Funcionalidades

# 

# \- Menu interativo no terminal

# \- Validaçao de entrada de dados com int.TryParse

# \- Adicionar novas tarefas

# \- Listar tarefas cadastradas

# \- Marcar tarefa como concluida

# \- Remover tarefas

# 

# \---

# 

# \## Tecnologias Utilizadas

# 

# \- Linguagem: C# (.NET 8.0)

# \- Ferramentas: Visual Studio Code / Visual Studio, Git e GitHub

# 

# \---

# 

# \## Como Rodar o Projeto

# 

# 1\. Certifica-te de ter o .NET SDK instalado no teu computador.

# 2\. Abre o terminal na pasta do projeto (task-tracker-cli).

# 3\. Executa o comando:

# 

# dotnet run

#
